Project brief
Build your own portfolio site from scratch — the site you would link on a CV.

Requirements

At least four sections: hero/about, skills, projects, contact.
Semantic HTML (header, nav, main, section, footer).
A responsive layout that works at 360px and 1280px.
A contact form (no backend needed — just valid, labeled fields).
Tips: start mobile-first; commit early and often.



Deliverables

Link to a public Github repo
Portfolio published using Github Pages
A 2 minutes max video, published in Youtube (unlisted), describing the top 2 challenges you've faced in this project
The Github repo must contain a README.md file, with the link to the Github Pages published site and the video

Considerations
Using AI is allowed, but it should not replace the student as the main author of the code.  The teacher might request a sync review if not enough evidence of a human process
